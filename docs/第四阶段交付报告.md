## 一、改了什么

### A. 降噪（服务器端）

| 问题（10-20 手机截图） | 现在 |
|---|---|
| 每天 21:20 重复写一遍「AVGO / MCD / META / NVDA / PDD 低估值」 | 「可买 / 低估值 / 极低估值」只在**刚进入**这个状态时单独记一条；之后还在同一状态就并成一条「[盘前] 估值汇总 · N 个标的」，默认折叠，点开看明细。离开状态再进入算新的一次；档位变了（低估值→极低估值）也算新状态 |
| 「UDOW Z 0.38 → 0.52 · 接近卖出区 +1.5」措辞不准 | 按当前 \|Z\| 分档：≥1.5 写「进入买入/卖出区」，≥1.2 才写「接近…±1.5」，其余只写「偏强 / 偏弱」 |
| Z 每穿过 ±0.5 就记一行 | 同一标的、同一类提醒 60 分钟内最多 1 条（重要级别不受限；真发出去的推送不会被挡）。分钟数写在 `deploy/alert-noise.config.json`，不做成界面开关 |
| 「FUTU 买入 NVDA 0.005 @ $216.00」 | 市值 < $10 或不足 1 股的残留不再记成交易，也不再写持仓变化提醒；已有的旧记录标「已作废 · 零碎持仓」，一行都不删（网关启动时自动修一次） |
| 「仅记录」条目太多 | 默认折叠，面板上新增「显示全部」开关；「只看重要」保留 |

推送本身一个字没改：开关、免打扰、连发次数照旧，只改「写不写日志那一行」。

### B. 手机上一眼看懂

- 每条默认一行：`21:38 🔴 UDOW $67.41 Z 0.52 偏强`，点一下展开完整说明、汇总明细、北京/美东时间、推送原因。
- 推送状态改成行尾小图标：📲 已推送 · 🔕 未推送 · 🌙 免打扰 · ❌ 推送失败 · ⏳ 重试中，原因文字在长按/悬停的提示里。
- 没点过的重要提醒置顶，左边一条颜色竖条（买入绿、卖出红、风险橙），点过之后回到时间顺序。
- 面板内显示未读数；每台设备记住上次打开时间，之后新增的条目上方画一条「—— 以下是新提醒 ——」。
- 深色面板和等宽字体保持原样；去掉了横向滚动。

### C. 顶部实时状态条

筛选按钮上方一排五张小卡片，每 60 秒更新：QQQ（现价、离前高 %）· VIX（数值、较昨收 %，上涨红 ↑）· CNN（数值、较上次箭头）· 今日重要 N 条 · 当前时段（盘前/盘中/盘后/夜盘/休市）。下面标数据时间；取数失败保留上一份数字并标「数据延迟」。

时段由服务器判定（假期表在服务器那边），`/api/quotes` 的返回里多了 `session` 和 `time` 两个字段。

### D. 让日志能行动

- 展开一条提醒 →「查看详情」：日志页内弹出只读侧边面板，复用决策页同一套图表（价格、均线、Z-Score）并显示远期 PE 和档位。**决策页本身一行没改**，面板里不能下单、不能改设置。
- 「我据此下单了」：在决策日志里生成一条草稿，自动带标的、方向、时间，并记下是哪条提醒带来的；数量、价格、预判留给你补（决策日志那条显示「数量待补 · 提醒草稿」，展开后有补数量的输入框）。

### E. 提醒效果

- 服务器每天收盘审查之后算一次：每条提醒按当天完整收盘价起算，之后第 1 / 5 / 20 个交易日该标的的涨跌 + 同期 QQQ + 超额；没到时间的显示「待定」。结果存成 `alert-outcomes.json`，网页只读（新接口 `GET /api/portfolio/alert-outcomes`）。
- 日志页新增第四个分页「📊 提醒效果」：按九类统计（QQQ 回撤档位、VIX 飙升、CNN 恐慌、Z 进入 ±1.5、Z 穿过 ±1.0、个股大涨大跌、卖出线、多指标共振、可买/低估值），每类显示次数、5 日和 20 日平均涨跌、20 日胜率、20 日超额；样本 < 10 次标「样本太少，结论不可靠」；回填的计入但单独标注；已作废的不计。
- 展开单条提醒也能看到这条自己的 1 / 5 / 20 天表现。

   带着「数量待补 · 提醒草稿」和来源提醒原文。

   QQQ 回撤档位那一组已经有数（含 4 条回填）。

## 四、我替你做的默认决定

| 决定 | 理由 |
|---|---|
| 推送行为完全不动，只改日志怎么记 | 你说推送开关和免打扰时段自己管 |
| 冷却只挡「没真的推出去」的条目 | 真发到手机上的提醒必须在日志里留痕 |
| 导航栏「日志」标签**没有**加未读小红点 | 你说的是「如果要加」；加它要动顶部导航，风险大于收益。未读数放在日志页面板内 |
| CNN / VIX / 共振这类看之后 QQQ 的走势 | CNN 不可交易、VIX 自己涨跌没有参考意义 |
| 「我据此下单了」的方向按提醒判断（红橙→卖出，其余→买入） | 你补数量和价格时能顺手改 |
| 行里的时间只到分钟（21:38），完整日期放在展开后和悬停提示里 | 一行放得下才是一行 |
| 已有的零碎记录由网关启动时自动标作废 | 不用你登服务器手动跑脚本；只加标记、不删数据 |

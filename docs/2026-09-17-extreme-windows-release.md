# Z-Score 阈值提醒与独立发送时段

## 范围与约定

- 用户明确选择“每类设置允许发送的时间段，时段外不发送”，不是延时汇总或排队补发。
- 在通知抽屉的露头提醒下加入“Z-Score 极值附近提醒”，正负方向分别配置阈值，默认 +1.4 / −1.4，三个新开关默认关闭。
- 五个普通提醒类别，以及露头、阈值提醒各自的栏目和方向，都能设置允许时段、星期、时区。设置折叠展示；原有 14 项固定报告仍可逐项设置准确时间。
- 全局开关、免打扰、栏目和方向的开关/时段、消息时效共同生效；时段外直接跳过，不排队、不补历史。
- 完整收盘数据确认首次进入阈值区域；持续处于区域不重复推送，退出再进入重新触发。默认收盘审查仍为美东 16:20，允许时段不会改变计算时间。
- 不修改 ±1.5 图表区间、回撤买入规则、顶部三个指标卡片或密码策略。先斜率曲线、后 PE 的顺序保留。

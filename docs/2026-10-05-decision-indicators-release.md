# 决策主表 SMA / PE 位置摘要上线验收

日期：2026-10-05（洛杉矶）；发布于 2026-10-06 02:08 UTC。站点：https://www.myopenid.top/ 。

## 页面改动

- 在“决策 → 股票与指数决策”主表保留回撤、200DMA 年化斜率、Z-Score、当前信号，增加 SMA 短线 / 趋势与 PE 历史位置两列。
- 桌面主表使用全宽，详细判断放在表格下方；手机采用卡片布局，SMA 与 PE 并列展示。顶部三张市场卡片及技术图在前、PE 图在后的顺序不变。
- 点击主表行或常用标的，判断详情、技术图、PE 图使用同一标的。PE 缺失时仍保留所选标的并显示缺失，不自动换成 NVDA 等其他股票。
- PE 用“低 → 高”位置条、当前位置圆点、分位、相对历史中位的上下箭头说明位置；详情及完整 PE 图仍保留当前 PE、30% 位、中位、70% 位。
- QQQ / TQQQ 的 PE 可明确引用 NDX；VOO / SPY 可明确引用 SPX。价格、均线和斜率仍使用标的自身数据。DIA 维持官方指数 PE 和“无可靠历史分位”的说明。

## 指标口径与安全边界

- 新 SMA 摘要固定使用 8 个交易日回看、%/天，只读取完整收盘点；不将原有 20 日回看、252 日年化值当成日斜率。三条均线为 20DMA、50DMA、200DMA，50DMA 在详情及原曲线中保留。
- 20DMA “短线偏热”：当前斜率为正，且处于自身最多近 5 年历史斜率的前 10%。采用中秩分位避免相等值全部误判为高位；至少需要 252 个有效样本。页面说明这是相对历史速度，不是收益预测。负斜率处于后 10% 时称“下行速度偏快”，不直接称为超卖。
- 200DMA：前一完整收盘斜率非负、当前为负时为“下穿零轴”；当前严格等于零为“触及零轴”；持续负值为“零轴下方”。这三种状态显示红色重点检查提示。
- 仍为正值但不大于 0.01%/天时，仅显示琥珀色“接近零轴”，不冒充已触零。极小非零值保留符号及足够精度，避免四舍五入成 0 造成误读。
- 风险提示要求核查个股营收、利润、现金流、负债与公告，指数 / ETF 核查成分股盈利和行业风险；不声称单凭技术指标就确认业绩恶化、超卖或“暴雷”。本次未新增自动基本面审计。
- PE 分位是相对自身历史的位置，不是上涨概率。零值、负值、缺失 PE 不标记为低估；无可靠历史不画虚假位置点。
- 原有回撤优先裁决、Z-Score 正负观察区、推送阈值和通知开关不变。本次严重提醒是站内视觉提示，不新增手机推送。

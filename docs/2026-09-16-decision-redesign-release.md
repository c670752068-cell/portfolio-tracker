# 决策页面改版发布记录

## 范围和规则

- 按用户批准的四张参考图改造决策页：紧凑股票列表、筛选、判断详情、PE 历史、技术图表。
- CNN、纳指估值、VIX 三张市场卡片的内容和组件保持不变；总览不放入新的决策工作区。
- 持仓标签与回撤、均线斜率、Z-Score 独立显示。回撤用快照及原有基准关系；年化斜率用自身 200DMA 的 20 个交易日变化、252 日年化。
- Z ≤ -1.50 为绿色买入区，Z ≥ +1.50 为红色卖出区；接近区边界为 ±1.25。通道与 Z 阈值属于同一条件，不重复计票。
- 筛选采用完整收盘信号，盘中预览单独标示。Z 阈值提醒不覆盖服务器原有正式买入裁决，也不自动下单；没有新增 PE 否决规则。
- 技术图按股价、Z-Score、三条 SMA 斜率、成交量排序，提供日期和时间范围联动。技术斜率默认 8 日回看、%/天，不冒充 20 日年化口径。
- 矮屏横向布局解除顶部吸附；中等宽度导航改为两行，避免顶部挤高遮挡图表。未增加密码或认证。
